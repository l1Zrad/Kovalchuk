\## Порядок запуска проекта



Все используемые программы являются портативными и запускаются в среде Windows без прав администратора из папки `%USERPROFILE%\\tools`.



\### 1. Подготовка окружения и запуск Node-RED

1\. Запустите командную строку с настроенными путями Git, Node.js и SQLite, дважды щелкнув по файлу:

&#x20;  `tools\\env.bat`

2\. Перейдите в корень папки проекта и запустите среду потокового программирования:

&#x20;  `start-nodered.bat`

3\. Откройте веб-браузер и перейдите в интерфейс редактора по адресу:

&#x20;  \[http://localhost:1880](http://localhost:1880)

4\. В правом верхнем углу редактора выберите меню \*\*≡\*\* -> \*\*Import\*\*, укажите файл конфигурации потока `nodered/flow.json` и нажмите кнопку \*\*Deploy\*\*.



\### 2. Инициализация базы данных SQLite

Если база данных `db/variant.db` отсутствует или её нужно пересоздать, выполните в консоли команду:

`sqlite3 db\\variant.db ".read db\\schema.sql"`



\### 3. Запуск симуляции и сбор логов

1\. Откройте проект в симуляторе Wokwi (ссылка указана выше).

2\. Запустите симуляцию кнопкой \*\*Start Simulation\*\*.

3\. Дождитесь выполнения циклов опроса датчиков, скопируйте текстовые строки из панели \*\*Serial Monitor\*\*.

4\. Вставьте скопированные данные в файл журнала `data/log.txt` и сохраните его. После этого узел `watch` в Node-RED автоматически обнаружит изменения и запустит разбор журнала.



\### 4. Проверка результатов и контроль данных

Для проверки корректности загрузки данных в СУБД SQLite выполните контрольные запросы:

`sqlite3 db\\variant.db ".read db\\queries.sql"`
